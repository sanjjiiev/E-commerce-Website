This project is a fully functional E-commerce Website built with Django. It provides essential features for managing products, users, orders, and payments. The system is designed to be scalable, secure, and user-friendly.

Features

User Authentication

Registration, login, and logout
Profile management
Secure password handling

Product Management

Categories and subcategories
Product search and filtering
Detailed product pages with descriptions and pricing

Shopping Cart

Add, update, and remove items
Persistent cart linked to user accounts

Order Management

Place orders with selected items
Track order history and status
Payment Integration

Admin Dashboard

Manage products, categories, and inventory
View and manage orders
User management

Technologies Used

Backend: Django, Django REST Framework
Frontend: HTML5, CSS3, JavaScript
Database: SQLite (development)
Authentication: Django’s built-in auth system
